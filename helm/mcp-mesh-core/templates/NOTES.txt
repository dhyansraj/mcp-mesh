  kubectl get secret {{ include "mcp-mesh-core.postgresCredentialsSecretName" . }} -n {{ .Release.Namespace }} \

{{- /* Only fires on the real remaining hazard: namespaceCreate renders
       global.namespace, which is independent of -n. Uninstall safety itself
       needs no warning — the Namespace carries resource-policy: keep. */}}
{{- $nsObject := .Values.global.namespace | default .Release.Namespace }}
{{- if and .Values.namespaceCreate (ne $nsObject .Release.Namespace) }}

WARNING: namespaceCreate rendered Namespace/{{ $nsObject }}, but this release
deploys into {{ .Release.Namespace }}. Nothing runs in {{ $nsObject }} — it is a stray
namespace, and every core release leaving global.namespace at its default
contends for that same object. Set global.namespace={{ .Release.Namespace }} to match -n.

Do not fix this by setting namespaceCreate=false on an existing release: that
drops the Namespace from the rendered manifest, and the next `helm upgrade`
deletes it along with everything inside.
{{- end }}
